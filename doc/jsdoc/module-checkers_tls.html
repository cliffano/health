    • checkers/tls

    TLS checker, built on the core tls module. Works against any TLS port (HTTPS, SMTPS, IMAPS, LDAPS, databases, ...). `rejectUnauthorized` defaults to false so that invalid certificates can be inspected and asserted on (`authorized: false`) instead of erroring out.
