    • matcher

    Expectation matcher. An expected value can be: - a scalar: strict equality - an array: deep equality - a plain object: partial deep match, only the listed keys are checked - an operator object: every key starts with `$` Supported operators: `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte`, `$contains`, `$matches`, `$exists`, `$in`, `$length`, `$not`, `$type`.
